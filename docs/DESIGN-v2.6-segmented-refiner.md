# v2.6 — 約5秒ずつ処理して結合（実装承認済み）

ユーザーが5秒単位処理の提案に「やって」と指示。既存の単一GPU worker内で、入力を選択fpsに基づく約5秒分の整数フレームへ分割し、上流のフォルダ処理でモデルを一度だけ読み込む。各区間を保存後、区間テンソル・KV/VAEキャッシュを解放する。最後に区間を順番に結合し、元の正規化入力の音声を一度だけ付ける。

入力の分割は1回のFFmpeg処理、区間境界でkeyframeを作り、映像はlossless H264で保存する。音声は区間へ含めない。末尾が短くても削除しない。区間ごとに4n+1へ必要分だけパディングし、元の区間フレーム数まで戻す。最終フレーム数・fps・既存音声保持を維持する。5秒以下は従来経路。

区間間のちらつきはあり得る。5秒でもメモリに収まる保証はせず、失敗時は通常のエラーとする。自動再試行・常駐サービス・新しい安全機構・長尺GPU試験は追加しない。既存緊急停止は維持する。v2.5の詳細進捗は設計のみのまま、今回の実装に混ぜない。
